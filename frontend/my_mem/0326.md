## 2. 并发任务限制问题

**问题**：批量分析时提示"最多同时执行3个任务"。

**原因**：开源版的设计限制，定义在 `app/services/queue/keys.py`：

```python
# 配置常量 - 开源版限制
DEFAULT_USER_CONCURRENT_LIMIT = 3
GLOBAL_CONCURRENT_LIMIT = 3  # 开源版全局最大并发限制为3
```

**限制原因**：
1. 资源保护 - 股票分析是计算密集型任务
2. 防止内存溢出、CPU满载、API速率限制触发

**修改方法**：
- MongoDB: `db.system_settings.updateOne({key: "max_concurrent_tasks"}, {$set: {value: 5}})`
- 代码: 修改 `DEFAULT_USER_CONCURRENT_LIMIT` 值

## 3. 港股批量分析失败问题

**问题**：股票代码 `01810`（港股小米）批量分析失败，错误信息"A股代码格式错误"。

**原因**：批量分析混合市场股票时，前端不传 `market_type`，后端默认使用"A股"导致港股代码验证失败。

**修改文件**：`app/routers/analysis.py`

**修改内容**：为每个股票自动识别市场类型

```python
from tradingagents.utils.stock_utils import StockUtils

# 自动识别市场类型
stock_market = StockUtils.identify_stock_market(symbol)
if stock_market.value == "china_a":
    inferred_market_type = "A股"
elif stock_market.value == "hong_kong":
    inferred_market_type = "港股"
elif stock_market.value == "us":
    inferred_market_type = "美股"
else:
    inferred_market_type = "A股"

# 如果参数中没有指定市场类型，使用自动识别的结果
params = request.parameters.model_copy() if request.parameters else AnalysisParameters()
if not params.market_type:
    params.market_type = inferred_market_type
```

## 4. 学习中心页面加载失败

**问题**：学习中心文章页面显示"页面加载失败"。

**原因**：前端 Docker 容器没有挂载 `docs` 目录，导致 Markdown 文件无法加载。

**修改文件**：`docker-compose.dev.yml`

**修改内容**：

```yaml
services:
  frontend:
    volumes:
      # ... 其他挂载
      # 添加文档目录挂载
      - ./docs:/app/docs
```

**重启命令**：
```bash
docker compose -f docker-compose.hub.nginx.yml -f docker-compose.dev.yml up -d frontend
```

## 5. 港股股票名称无法自动获取

**问题**：添加自选股时，港股无法自动获取股票名称。

**原因**：前端 `fetchStockInfo` 函数只支持 A 股，港股/美股没有调用后端 API。

**修改文件**：
1. `app/routers/stock_data.py` - 新增港股/美股基础信息 API
2. `frontend/src/views/Favorites/index.vue` - 前端调用新 API

**后端新增 API**：

```python
@router.get("/foreign-info/{market}/{symbol}")
async def get_foreign_stock_info(
    market: str,  # HK/US
    symbol: str,
    current_user: dict = Depends(get_current_user)
):
    """获取港股/美股基础信息"""
    from app.services.foreign_stock_service import ForeignStockService
    
    service = ForeignStockService(db=db)
    if market.upper() == 'HK':
        info = await service._get_hk_info(symbol, force_refresh=False)
        # 返回包含 name 的信息
    elif market.upper() == 'US':
        info = await service._get_us_info(symbol, force_refresh=False)
        # 返回包含 name 的信息
```

**前端修改**：

```typescript
const fetchStockInfo = async () => {
  const market = addForm.value.market

```

```typescript
// 标签排序方法
const sortByTags = (a: any, b: any) => {
  const tagsA = a.tags || []
  const tagsB = b.tags || []
  if (tagsA.length === 0 && tagsB.length === 0) return 0
  if (tagsA.length === 0) return 1
  if (tagsB.length === 0) return -1
  return tagsA[0].localeCompare(tagsB[0], 'zh-CN')
}
```
