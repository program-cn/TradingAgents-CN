# 源码修改与容器更新联动指南

## 概述

本文档说明如何在修改 TradingAgents-CN 源码后，让容器环境更新并展示效果。根据不同场景，提供三种联动方式。

---

## 方式对比

| 方式 | 适用场景 | 更新速度 | 复杂度 | 推荐度 |
|------|---------|---------|--------|--------|
| **方式一：重新构建镜像** | 正式部署、代码提交后 | 慢（5-10分钟） | 简单 | ⭐⭐⭐ |
| **方式二：挂载本地代码** | 开发调试、频繁修改 | 快（即时） | 中等 | ⭐⭐⭐⭐⭐ |
| **方式三：本地源码运行** | 深度开发、断点调试 | 最快（即时） | 较高 | ⭐⭐⭐⭐ |

---

## 方式一：重新构建镜像（推荐用于正式更新）

### 适用场景
- 代码修改完成，需要部署到生产环境
- 需要确保运行环境完全一致
- 多人协作，需要统一构建产物

### 操作步骤

#### 1. 修改源码

```bash
# 进入项目目录
cd /home/robot/agi/TradingAgents-CN

# 修改后端代码
vim app/main.py  # 或其他文件

# 修改前端代码
vim frontend/src/App.vue  # 或其他文件
```

#### 2. 重新构建镜像

```bash
# 方式A：使用 docker-compose.yml（本地构建）
docker compose build backend frontend

# 方式B：使用 docker-compose.hub.nginx.yml（带 Nginx）
docker compose -f docker-compose.hub.nginx.yml build backend frontend

# 仅构建后端
docker compose build backend

# 仅构建前端
docker compose build frontend
```

# 方式1: 加 --build 标志
docker compose -f docker-compose.hub.nginx.yml -f docker-compose.dev.yml up -d --build

# 方式2: 先构建再启动
docker compose -f docker-compose.hub.nginx.yml build backend
docker compose -f docker-compose.hub.nginx.yml -f docker-compose.dev.yml up -d



**构建输出示例**：
```
[+] Building backend
 => [internal] load build definition from Dockerfile.backend
 => [internal] load .dockerignore
 => [internal] load metadata for python:3.10-slim-bookworm
 => [1/8] FROM python:3.10-slim-bookworm
 ...
 => exporting to image
 => => naming to docker.io/library/tradingagents-backend:v1.0.0-preview
```

#### 3. 重启服务

```bash
# 停止旧容器并启动新容器
docker compose -f docker-compose.hub.nginx.yml up -d

# 或仅重启特定服务
docker compose -f docker-compose.hub.nginx.yml up -d backend
docker compose -f docker-compose.hub.nginx.yml up -d frontend
```

#### 4. 验证更新

```bash
# 查看容器状态
docker compose -f docker-compose.hub.nginx.yml ps

# 查看后端日志
docker logs -f tradingagents-backend

# 访问系统验证
curl http://localhost/api/health
```

### 完整流程脚本

```bash
#!/bin/bash
# 构建并更新.sh

cd /home/robot/agi/TradingAgents-CN

echo "🔨 构建后端镜像..."
docker compose -f docker-compose.hub.nginx.yml build backend

echo "🔨 构建前端镜像..."
docker compose -f docker-compose.hub.nginx.yml build frontend

echo "🔄 重启服务..."
docker compose -f docker-compose.hub.nginx.yml up -d

echo "📋 查看状态..."
docker compose -f docker-compose.hub.nginx.yml ps

echo "✅ 更新完成！"
```

## 方式二：挂载本地代码（推荐用于开发调试）

### 适用场景
- 开发阶段，需要频繁修改代码
- 希望修改后立即看到效果
- 需要保留容器内的数据库和缓存服务

### 原理说明

将本地源码目录挂载到容器内，容器直接使用本地代码运行：

```
宿主机                           容器
/home/robot/agi/TradingAgents-CN/app  →  /app/app
/home/robot/agi/TradingAgents-CN/frontend/src  →  /app/frontend/src
```

### 配置步骤

#### 1. 创建开发配置文件

创建 `docker-compose.dev.yml`：

```yaml
version: '3.8'

# 开发环境配置 - 挂载本地代码
# 使用方法：docker compose -f docker-compose.hub.nginx.yml -f docker-compose.dev.yml up -d

services:
  backend:
    volumes:
      # 挂载后端源码（覆盖镜像内的代码）
      - ./app:/app/app
      - ./tradingagents:/app/tradingagents
      - ./scripts:/app/scripts
      - ./config:/app/config
      # 日志和数据目录
      - ./logs:/app/logs
      - ./data:/app/data
    environment:
      # 启用热重载
      - RELOAD=true
      - DEBUG=true

  frontend:
    # 开发模式：使用 Vite 开发服务器
    build:
      context: ./frontend
      dockerfile: Dockerfile.dev
    volumes:
      # 挂载前端源码
      - ./frontend/src:/app/frontend/src
      - ./frontend/public:/app/frontend/public
      - ./frontend/index.html:/app/frontend/index.html
    environment:
      - NODE_ENV=development
      - VITE_API_BASE_URL=http://localhost:8000/api
    ports:
      - "5173:5173"  # Vite 开发服务器端口
```

#### 2. 创建前端开发 Dockerfile

创建 `frontend/Dockerfile.dev`：

```dockerfile
FROM node:22-alpine

WORKDIR /app/frontend

# 启用 Corepack 和 Yarn
RUN corepack enable && corepack prepare yarn@1.22.22 --activate

# 复制依赖配置
COPY package.json yarn.lock .yarnrc ./

# 安装依赖
RUN yarn install --frozen-lockfile --network-timeout 300000

# 复制源码（会被 volume 挂载覆盖）
COPY . .

# 暴露 Vite 开发服务器端口
EXPOSE 5173

# 启动 Vite 开发服务器（支持热重载）
CMD ["yarn", "dev", "--host", "0.0.0.0"]
```

#### 3. 启动开发环境

```bash
# 启动数据库和后端（使用基础配置）
docker compose -f docker-compose.hub.nginx.yml up -d mongodb redis

# 启动后端（挂载本地代码）
docker compose -f docker-compose.hub.nginx.yml -f docker-compose.dev.yml up -d backend

# 启动前端（开发模式）
docker compose -f docker-compose.hub.nginx.yml -f docker-compose.dev.yml up -d frontend

# 查看日志
docker compose logs -f backend
docker compose logs -f frontend
```

#### 4. 修改代码并验证

```bash
# 修改后端代码
vim app/api/routes/health.py

# 修改前端代码
vim frontend/src/views/Home.vue

# 后端会自动重载（如果配置了 --reload）
# 前端会自动热更新（Vite HMR）

# 访问验证
curl http://localhost:8000/api/health
# 或浏览器访问 http://localhost:5173
```

### 快速启动脚本

创建 `dev-start.sh`：

```bash
#!/bin/bash
# 开发环境启动脚本

cd /home/robot/agi/TradingAgents-CN

# 启动前端（开发模式）
echo "🎨 启动前端（开发模式）..."
docker compose -f docker-compose.hub.nginx.yml -f docker-compose.dev.yml up -d frontend

echo ""
echo "✅ 开发环境已启动！"
echo ""
echo "📍 访问地址："
echo "   前端开发服务器: http://localhost:5173"
echo "   后端 API:       http://localhost:8000"
echo "   API 文档:       http://localhost:8000/docs"
echo ""
echo "📋 查看日志："
echo "   后端: docker compose logs -f backend"
echo "   前端: docker compose logs -f frontend"
echo ""
echo "🛑 停止服务："
echo "   docker compose -f docker-compose.hub.nginx.yml -f docker-compose.dev.yml down"
```

## 方式三：本地源码运行（推荐用于深度开发）

### 适用场景
- 需要使用 IDE 断点调试
- 需要完全控制运行环境
- 前后端分离开发

### 环境要求

- Python 3.10+
- Node.js 18+
- MongoDB 4.4+（可使用 Docker）
- Redis 6.0+（可使用 Docker）

### 操作步骤

#### 1. 启动数据库（Docker）

```bash
# 仅启动 MongoDB 和 Redis
docker compose -f docker-compose.hub.nginx.yml up -d mongodb redis
```

#### 2. 配置后端环境

```bash
cd /home/robot/agi/TradingAgents-CN

# 创建虚拟环境
python -m venv venv
source venv/bin/activate

# 安装依赖
pip install -e .

# 配置环境变量
cp .env.docker .env
# 编辑 .env，确保数据库连接使用 localhost
# MONGODB_URL=mongodb://admin:tradingagents123@localhost:27017/tradingagents?authSource=admin
# REDIS_URL=redis://:tradingagents123@localhost:6379/0
```

#### 3. 启动后端

```bash
# 激活虚拟环境
source venv/bin/activate

# 启动后端（带热重载）
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

# 或
python -m app
```

#### 4. 启动前端

```bash
cd /home/robot/agi/TradingAgents-CN/frontend

# 安装依赖
yarn install

# 启动开发服务器
yarn dev
```

#### 5. 访问应用

- 前端：http://localhost:5173
- 后端：http://localhost:8000
- API 文档：http://localhost:8000/docs

## 最佳实践

### 开发流程推荐

```
1. 功能开发阶段
   ↓ 使用方式三（本地源码运行）
   - 快速迭代
   - 断点调试
   - 单元测试
   
2. 功能测试阶段
   ↓ 使用方式二（挂载本地代码）
   - 完整环境测试
   - 集成测试
   
3. 提交部署阶段
   ↓ 使用方式一（重新构建镜像）
   - 构建生产镜像
   - 部署到测试/生产环境
```

### 常见问题

#### Q1: 挂载代码后权限问题？

```bash
# 修改文件权限
chmod -R 755 app/
chmod -R 755 frontend/

# 或在容器内修改
docker exec -it tradingagents-backend chown -R node:node /app
```

#### Q2: 后端代码修改后没有生效？

```bash
# 确保启用了 --reload 参数
uvicorn app.main:app --reload

# 或重启容器
docker restart tradingagents-backend
```

#### Q3: 前端修改后页面没有更新？

```bash
# 清除缓存重新构建
cd frontend
rm -rf node_modules/.vite
yarn dev

# 或强制刷新浏览器（Ctrl+Shift+R）
```

#### Q4: 如何同时开发前后端？

```bash
# 终端1：启动后端
source venv/bin/activate
uvicorn app.main:app --reload --port 8000

# 终端2：启动前端
cd frontend
yarn dev

# 浏览器访问 http://localhost:5173
# 前端会自动代理到后端 http://localhost:8000
```

## 快速命令参考

### 重新构建镜像

```bash
# 构建所有服务
docker compose -f docker-compose.hub.nginx.yml build

# 构建特定服务
docker compose build backend
docker compose build frontend

# 不使用缓存重新构建
docker compose build --no-cache backend

# 重启服务
docker compose -f docker-compose.hub.nginx.yml up -d
```

### 开发模式

```bash
# 启动开发环境
docker compose -f docker-compose.hub.nginx.yml -f docker-compose.dev.yml up -d

# 查看日志
docker compose logs -f backend

# 停止开发环境
docker compose -f docker-compose.hub.nginx.yml -f docker-compose.dev.yml down
```

### 本地运行

```bash
# 后端
source venv/bin/activate
uvicorn app.main:app --reload --port 8000

# 前端
cd frontend && yarn dev

# 数据库（Docker）
docker compose -f docker-compose.hub.nginx.yml up -d mongodb redis
```

## 总结

| 开发阶段 | 推荐方式 | 命令 |
|---------|---------|------|
| 功能开发 | 本地源码运行 | `uvicorn app.main:app --reload` |
| 集成测试 | 挂载本地代码 | `docker compose -f docker-compose.dev.yml up` |
| 正式部署 | 重新构建镜像 | `docker compose build && docker compose up -d` |

选择适合你当前开发阶段的方式，可以大大提高开发效率！
