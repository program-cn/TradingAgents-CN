# TradingAgents-CN 环境说明

## 系统架构概述

TradingAgents-CN v1.0.0-preview 采用现代化的微服务架构，主要包含以下组件：

### 核心组件

| 组件 | 容器名 | 镜像 | 端口 | 说明 |
|------|--------|------|------|------|
| Nginx | tradingagents-nginx | nginx:alpine | 80 | 反向代理，统一入口 |
| Frontend | tradingagents-frontend | hsliup/tradingagents-frontend | 80（内部） | Vue 3 前端应用 |
| Backend | tradingagents-backend | hsliup/tradingagents-backend | 8000（内部） | FastAPI 后端服务 |
| MongoDB | tradingagents-mongodb | mongo:4.4 | 27017 | 文档数据库 |
| Redis | tradingagents-redis | redis:7-alpine | 6379 | 缓存服务 |

## 数据库配置

### MongoDB 配置

```bash
# 默认配置
MONGODB_HOST=mongodb
MONGODB_PORT=27017
MONGODB_USERNAME=admin
MONGODB_PASSWORD=tradingagents123
MONGODB_DATABASE=tradingagents
MONGODB_AUTH_SOURCE=admin
```

**数据集合**：

| 集合名 | 说明 |
|--------|------|
| system_configs | 系统配置 |
| users | 用户数据 |
| llm_providers | LLM 提供商配置 |
| model_catalog | 模型目录 |
| market_categories | 市场分类 |
| user_tags | 用户标签 |
| datasource_groupings | 数据源分组 |
| platform_configs | 平台配置 |
| user_configs | 用户配置 |
| stock_basic_info | 股票基础信息 |
| market_quotes | 市场行情 |

### Redis 配置

```bash
# 默认配置
REDIS_HOST=redis
REDIS_PORT=6379
REDIS_PASSWORD=tradingagents123
REDIS_DB=0
```

**用途**：
- 会话缓存
- 实时行情缓存
- 任务队列
- 速率限制

## LLM 提供商配置

| 提供商 | 环境变量 | 获取地址 |


## 数据源配置

### 支持的数据源

| 数据源 | 环境变量 | 说明 |
|--------|---------|------|
| Tushare | `TUSHARE_TOKEN` | 专业金融数据，需注册 |
| AKShare | 默认启用 | 免费开源数据源 |
| BaoStock | 默认启用 | 免费开源数据源 |
| FinnHub | `FINNHUB_API_KEY` | 国际金融数据 |

### Tushare 配置

```bash
# Tushare Token（获取地址：https://tushare.pro/register?reg=tacn）
TUSHARE_TOKEN=your-token-here
TUSHARE_ENABLED=true

# 权限等级（影响调用频率）
TUSHARE_TIER=standard  # 可选：free, basic, standard, premium, vip

# 数据同步配置
TUSHARE_UNIFIED_ENABLED=true
TUSHARE_BASIC_INFO_SYNC_ENABLED=true
TUSHARE_HISTORICAL_SYNC_ENABLED=true
```

## 安全配置

### JWT 配置

```bash
# JWT 密钥（生产环境请修改！）
JWT_SECRET=docker-jwt-secret-key-change-in-production-2024
JWT_ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=480  # 8小时
REFRESH_TOKEN_EXPIRE_DAYS=30
```

### CSRF 配置

```bash
CSRF_SECRET=docker-csrf-secret-key-change-in-production-2024
BCRYPT_ROUNDS=12
```

**⚠️ 安全建议**：
- 生产环境请修改所有 `*_SECRET` 变量
- 使用强密码替换默认密码
- 定期更换 JWT 密钥

## 数据同步配置

### 股票基础信息同步

```bash
# 启用基础信息同步
SYNC_STOCK_BASICS_ENABLED=true
SYNC_STOCK_BASICS_TIME=06:30  # 每天早上 6:30 同步
```

### 实时行情同步

```bash
# 启用实时行情入库
QUOTES_INGEST_ENABLED=true
QUOTES_INGEST_INTERVAL_SECONDS=360  # 每 6 分钟更新

# 启用接口轮换
QUOTES_ROTATION_ENABLED=true

# Tushare 实时行情限制
QUOTES_TUSHARE_HOURLY_LIMIT=2  # 免费用户每小时 2 次
```

### Tushare 数据同步

```bash
TUSHARE_UNIFIED_ENABLED=false  # 总开关

# 基础信息同步（每天凌晨 2 点）
TUSHARE_BASIC_INFO_SYNC_ENABLED=false
TUSHARE_BASIC_INFO_SYNC_CRON=0 2 * * *

# 行情同步（交易时间每分钟）
TUSHARE_QUOTES_SYNC_ENABLED=false
TUSHARE_QUOTES_SYNC_CRON=*/1 9-15 * * 1-5

# 历史数据同步（工作日 16 点）
TUSHARE_HISTORICAL_SYNC_ENABLED=false
TUSHARE_HISTORICAL_SYNC_CRON=0 16 * * 1-5

# 财务数据同步（周日凌晨 3 点）
TUSHARE_FINANCIAL_SYNC_ENABLED=false
TUSHARE_FINANCIAL_SYNC_CRON=0 3 * * 0
```

## 端口配置

### 默认端口映射

| 服务 | 容器端口 | 宿主机端口 |
|------|---------|-----------|
| Nginx | 80 | 80 |
| MongoDB | 27017 | 27017 |
| Redis | 6379 | 6379 |

### 修改端口

编辑 `docker-compose.hub.nginx.yml`：

```yaml
# 修改 Nginx 端口（例如改为 8080）
nginx:
  ports:
    - "8080:80"  # 改为 8080:80
```

**注意**：MongoDB 和 Redis 端口仅用于开发调试，生产环境建议不暴露。

## 故障排除

### 查看容器状态

```bash
docker compose -f docker-compose.hub.nginx.yml ps
```

### 查看容器日志

```bash
# 所有服务日志
docker compose -f docker-compose.hub.nginx.yml logs -f

# 特定服务日志
docker logs -f tradingagents-backend
docker logs -f tradingagents-mongodb
docker logs -f tradingagents-nginx
```

### 进入容器调试

```bash
# 进入后端容器
docker exec -it tradingagents-backend bash

# 进入 MongoDB 容器
docker exec -it tradingagents-mongodb bash

# 连接 MongoDB
docker exec -it tradingagents-mongodb mongo -u admin -p tradingagents123 --authenticationDatabase admin
```

### 检查网络连接

```bash
# 检查容器网络
docker network inspect tradingagents-network

# 测试服务间连接
docker exec tradingagents-backend curl http://mongodb:27017
docker exec tradingagents-backend curl http://redis:6379
```
