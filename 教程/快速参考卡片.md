# TradingAgents-CN 快速参考卡片

## 一、安装命令速查

### 从项目源码部署

```bash
# 1. 创建目录
mkdir -p ~/tradingagents-demo && cd ~/tradingagents-demo

# 2. 复制配置文件
cp /path/to/TradingAgents-CN/docker-compose.hub.nginx.yml .
cp /path/to/TradingAgents-CN/.env.docker . && mv .env.docker .env
mkdir -p nginx && cp /path/to/TradingAgents-CN/nginx/nginx.conf nginx/

# 3. 配置 API 密钥
nano .env  # 至少配置一个 LLM 提供商

# 4. 拉取镜像
docker compose -f docker-compose.hub.nginx.yml pull

# 5. 启动服务
docker compose -f docker-compose.hub.nginx.yml up -d

# 6. 导入配置
docker exec -it tradingagents-backend python scripts/import_config_and_create_user.py

# 7. 重启后端
docker restart tradingagents-backend
```

## 二、常用命令

### 服务管理

| 操作 | 命令 |
|------|------|
| 查看状态 | `docker compose -f docker-compose.hub.nginx.yml ps` |
| 启动服务 | `docker compose -f docker-compose.hub.nginx.yml up -d` |
| 停止服务 | `docker compose -f docker-compose.hub.nginx.yml down` |
| 重启服务 | `docker compose -f docker-compose.hub.nginx.yml restart` |
| 更新镜像 | `docker compose -f docker-compose.hub.nginx.yml pull && docker compose -f docker-compose.hub.nginx.yml up -d` |

### 日志查看

| 操作 | 命令 |
|------|------|
| 所有日志 | `docker compose -f docker-compose.hub.nginx.yml logs -f` |
| 后端日志 | `docker logs -f tradingagents-backend` |
| Nginx 日志 | `docker logs -f tradingagents-nginx` |
| MongoDB 日志 | `docker logs -f tradingagents-mongodb` |

### 数据库操作

| 操作 | 命令 |
|------|------|
| 连接 MongoDB | `docker exec -it tradingagents-mongodb mongo -u admin -p tradingagents123 --authenticationDatabase admin` |
| 连接 Redis | `docker exec -it tradingagents-redis redis-cli -a tradingagents123` |
| 备份数据 | `docker exec tradingagents-mongodb mongodump -u admin -p tradingagents123 --authenticationDatabase admin -d tradingagents -o /backup` |

## 五、故障排除

### 服务无法启动

```bash
# 检查端口占用
sudo netstat -tulpn | grep :80

# 查看错误日志
docker compose -f docker-compose.hub.nginx.yml logs
```

### 无法访问系统

```bash
# 检查防火墙
sudo ufw status

# 开放端口
sudo ufw allow 80
```

### 后端连接失败

```bash
# 检查健康状态
curl http://localhost:8000/api/health

# 查看后端日志
docker logs tradingagents-backend --tail 100
```
