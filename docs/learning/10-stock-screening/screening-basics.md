# 股票筛选入门指南

## 概述

股票筛选是投资者在海量股票中快速找到符合特定条件标的的有效方法。TradingAgents-CN 提供了强大的多维度股票筛选功能，支持基本面和技术面相结合的筛选策略。

## 筛选功能入口

在系统导航栏点击「股票筛选」即可进入筛选页面。

## 筛选维度概览

| 维度 | 类别 | 说明 |
|------|------|------|
| 市场类型 | 基础 | 选择股票所在市场（当前支持A股） |
| 行业分类 | 基础 | 按申万一级行业分类筛选 |
| 市值范围 | 基础 | 小盘股、中盘股、大盘股分类 |
| 市盈率(PE) | 估值 | 评估股票估值水平 |
| 市净率(PB) | 估值 | 评估股价与净资产关系 |
| ROE | 财务 | 净资产收益率，衡量盈利能力 |
| 涨跌幅 | 技术 | 筛选涨跌幅度区间 |
| 成交量 | 技术 | 筛选成交活跃度 |

## 基本使用流程

### 步骤一：设置筛选条件

1. **选择行业**：可多选，不选则查询全市场
2. **选择市值范围**：
   - 小盘股：市值 < 100亿
   - 中盘股：市值 100-500亿
   - 大盘股：市值 > 500亿
3. **设置估值指标**：填写市盈率、市净率范围
4. **设置财务指标**：填写ROE范围
5. **设置交易指标**：填写涨跌幅、成交量要求

### 步骤二：执行筛选

点击「开始筛选」按钮，系统将根据设置的条件查询符合条件的股票。

### 步骤三：分析结果

筛选结果将显示：
- 股票代码和名称
- 所属行业
- 当前价格和涨跌幅
- 市值规模
- 估值指标（PE、PB）
- 盈利能力（ROE）

### 步骤四：后续操作

- **单只分析**：点击「分析」按钮，跳转到个股深度分析
- **加入自选**：将股票加入自选列表，方便跟踪
- **批量分析**：勾选多只股票后，点击「批量分析」进行批量处理

## 筛选策略示例

### 价值投资策略

寻找被低估的优质股票：

```
行业：不限
市值：中盘股、大盘股
市盈率：5 - 15
市净率：0.8 - 2.0
ROE：10% 以上
```

此策略筛选出估值合理、盈利能力较强的中大盘股。

### 成长投资策略

寻找高成长的潜力股：

```
行业：科技、医药、新能源
市值：中盘股
市盈率：20 - 50（成长股估值较高）
ROE：15% 以上
涨跌幅：不限
成交量：活跃
```

此策略关注高成长行业，选择盈利能力强、市场关注度高的股票。

### 低估值策略

寻找安全边际较高的股票：

```
行业：不限
市值：大盘股
市盈率：0 - 10
市净率：0.5 - 1.0
ROE：8% 以上
```

此策略筛选出价格低于净资产的股票，具有较高的安全边际。

### 高股息策略

寻找分红稳定的股票：

```
行业：银行、公用事业、交通运输
市值：大盘股
市盈率：5 - 15
ROE：10% 以上
```

此类股票通常具有稳定的现金流和分红能力。

## 筛选结果解读

### 关键指标解读

| 指标 | 低值含义 | 高值含义 | 理想区间 |
|------|----------|----------|----------|
| PE | 被低估或增长预期低 | 高增长预期或高估 | 行业平均附近 |
| PB | 资产价值被低估 | 市场看好未来发展 | 1-3倍 |
| ROE | 盈利能力弱 | 盈利能力强 | >15% |

### 市值分类解读

| 类型 | 市值范围 | 特点 |
|------|----------|------|
| 小盘股 | <100亿 | 成长空间大，波动性高，流动性一般 |
| 中盘股 | 100-500亿 | 成长性与稳定性兼顾，适合大多数投资者 |
| 大盘股 | >500亿 | 稳定性高，流动性好，增长相对缓慢 |

## 注意事项

### 数据时效性

- 筛选数据基于最新交易日收盘数据
- 财务指标（PE、PB、ROE）基于最新财报数据
- 实时数据会显示「实时」标签

### 筛选限制

- 单次筛选最多返回500只股票
- 建议设置合理的筛选条件缩小范围

### 风险提示

- 筛选结果仅供参考，不构成投资建议
- 需要结合深度分析做出投资决策
- 历史表现不代表未来收益

## 进阶使用

### 组合筛选

可以结合多个维度进行组合筛选，例如：
- 同时使用估值指标和技术指标
- 结合行业轮动选择热门行业
- 根据市场情绪调整筛选条件

### 定期复盘

建议定期（如每月）执行相同的筛选策略：
- 观察筛选结果的变化
- 追踪之前筛选出的股票表现
- 优化筛选参数
