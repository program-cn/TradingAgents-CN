# 估值指标详解

## 概述

估值指标是判断股票是否具有投资价值的重要工具。通过对比股票当前价格与公司内在价值，投资者可以判断股票是否被低估或高估。

## 市盈率 (PE)

### 定义

市盈率（Price-to-Earnings Ratio）是股价与每股收益的比率，反映投资者愿意为每1元净利润支付多少元股价。

### 计算公式

```
PE = 股价 / 每股收益(EPS)
PE = 总市值 / 净利润
```

### 类型说明

| 类型 | 计算方式 | 特点 |
|------|----------|------|
| 静态PE | 当前股价 / 上年度EPS | 数据确定，但滞后 |
| 动态PE | 当前股价 / 预测EPS | 前瞻性，但预测不确定 |
| PE(TTM) | 当前股价 / 过去四个季度EPS | 兼顾时效性和确定性 |

### 应用方法

#### 行业对比法

不同行业的PE水平差异很大：

| 行业 | 典型PE范围 | 原因 |
|------|-----------|------|
| 银行 | 5-10倍 | 成长性低，盈利稳定 |
| 钢铁、煤炭 | 5-15倍 | 周期性强，波动大 |
| 消费品 | 15-30倍 | 品牌价值，稳定增长 |
| 科技 | 20-50倍 | 高成长预期 |
| 新能源 | 30-80倍 | 高增长预期 |

**投资启示**：
- PE低于行业平均，可能被低估
- PE高于行业平均，需要更高的成长性支撑

#### 历史对比法

对比股票自身历史PE区间：
- 当前PE处于历史低位（如20%分位以下）：可能被低估
- 当前PE处于历史高位（如80%分位以上）：可能被高估

### 使用注意事项

#### PE的局限性

1. **亏损企业不适用**：净利润为负时，PE无意义
2. **周期性行业需谨慎**：景气高点PE低，景气低点PE高
3. **一次性损益影响**：需剔除非经常性损益

#### PE陷阱

- **低PE陷阱**：看似便宜，实际可能是业绩下滑预期
- **高PE合理**：高成长公司可以支撑高PE

## 市净率 (PB)

### 定义

市净率（Price-to-Book Ratio）是股价与每股净资产的比率，反映股价相对于公司账面价值的溢价程度。

### 计算公式

```
PB = 股价 / 每股净资产
PB = 总市值 / 净资产
```

### 应用方法

#### 行业适用性

| 行业 | PB适用性 | 原因 |
|------|----------|------|
| 银行 | 非常适用 | 资产清晰，账面价值可靠 |
| 地产 | 适用 | 资产价值可评估 |
| 制造业 | 较适用 | 固定资产占比高 |
| 科技 | 参考使用 | 无形资产难计量 |
| 服务/互联网 | 不适用 | 轻资产模式 |

#### PB与ROE的关系

```
PB = 1 + (ROE - r) × g / (r - g)

其中：
- r = 要求回报率
- g = 增长率
```

**经验法则**：
- ROE > 15% 的公司，PB > 2 是合理的
- ROE < 10% 的公司，PB < 1 可能是合理的

### PB策略

#### 低PB策略

```
PB < 1：股价低于净资产
PB < 0.8：资产打折20%
```

**风险**：
- 可能存在资产质量问题
- 需要检查资产是否真实存在
- 行业前景是否持续恶化

#### PB-ROE选股法

结合PB和ROE两个指标：

| 组合 | 特征 | 投资价值 |
|------|------|----------|
| 低PB + 高ROE | 被低估的优质股 | ⭐⭐⭐⭐⭐ |
| 高PB + 高ROE | 成长股，需看增长持续性 | ⭐⭐⭐ |
| 低PB + 低ROE | 价值陷阱或周期底部 | ⭐⭐ |
| 高PB + 低ROE | 高估，应避免 | ⭐ |

## 市销率 (PS)

### 定义

市销率（Price-to-Sales Ratio）是股价与每股销售额的比率，适用于尚未盈利的成长型企业。

### 计算公式

```
PS = 股价 / 每股销售额
PS = 总市值 / 营业收入
```

### 适用场景

- **互联网企业**：早期未盈利，但有营收规模
- **生物医药**：研发期无利润，但研发管线有价值
- **SaaS企业**：订阅收入稳定，利润后置

### 参考标准

| PS范围 | 含义 |
|--------|------|
| PS < 2 | 传统行业估值水平 |
| PS 2-5 | 成长型企业 |
| PS 5-10 | 高增长预期 |
| PS > 10 | 极高增长预期，风险大 |

## 企业价值倍数 (EV/EBITDA)

### 定义

EV/EBITDA是企业价值与息税折旧摊销前利润的比率，比PE更全面地衡量企业价值。

### 计算公式

```
EV = 市值 + 净债务
EBITDA = 净利润 + 利息 + 税 + 折旧 + 摊销
EV/EBITDA = 企业价值 / EBITDA
```

### 优势

1. **剔除资本结构影响**：不同融资方式的公司可比
2. **剔除折旧政策影响**：不同折旧方法的公司可比
3. **适用于高负债企业**：如公用事业、航空业

### 参考标准

| EV/EBITDA | 含义 |
|-----------|------|
| < 6 | 可能被低估 |
| 6-10 | 合理区间 |
| 10-15 | 较高估值 |
| > 15 | 高估值 |

## 股息率 (Dividend Yield)

### 定义

股息率是年度股息与股价的比率，反映股票的现金回报能力。

### 计算公式

```
股息率 = 年度股息 / 股价 × 100%
```

### 应用场景

#### 收益型投资

```
高股息策略：
- 股息率 > 5%
- 连续分红3年以上
- 分红比例稳定（40%-60%）
```

#### 行业对比

| 行业 | 典型股息率 |
|------|-----------|
| 银行 | 4-6% |
| 公用事业 | 3-5% |
| 高速公路 | 3-4% |
| 消费品 | 2-3% |
| 科技 | 0-2% |

### 注意事项

1. **股息可持续性**：检查分红比例是否合理
2. **盈利稳定性**：波动大的行业股息不稳定
3. **股价波动**：股息率会随股价变化

## 估值指标综合应用

### 多指标验证

不应仅依赖单一指标，应综合判断：

```
低估信号：
✓ PE处于历史低位
✓ PB < 1.5
✓ EV/EBITDA < 8
✓ 股息率 > 3%
```

### 行业特性匹配

根据行业特性选择合适的估值方法：

| 行业类型 | 首选指标 | 辅助指标 |
|----------|----------|----------|
| 金融 | PB | PE、股息率 |
| 周期 | PB、EV/EBITDA | PE（景气高位反向看） |
| 消费 | PE | PB、股息率 |
| 科技成长 | PS | PE（盈利后） |
| 公用事业 | 股息率 | PB、PE |

## 实战案例

### 案例：银行股估值分析

假设某银行股数据：
- 股价：5元
- 每股收益：0.8元
- 每股净资产：6元
- 年度股息：0.25元

计算：
```
PE = 5 / 0.8 = 6.25倍
PB = 5 / 6 = 0.83倍
股息率 = 0.25 / 5 = 5%
```

判断：
- PE 6.25倍：低于银行行业平均（约7倍），估值合理偏低
- PB 0.83倍：股价低于净资产，具有一定安全边际
- 股息率 5%：现金回报率较高

综合评估：该银行股估值合理偏低，适合稳健型投资者。
