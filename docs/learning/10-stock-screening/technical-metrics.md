# 技术指标详解

## 概述

技术指标是分析股票价格走势和市场情绪的重要工具。与财务指标关注公司基本面不同，技术指标主要关注价格、成交量、波动等市场数据。

## 涨跌幅

### 定义

涨跌幅是衡量股票价格变化幅度的基本指标。

### 计算公式

```
涨跌幅 = (收盘价 - 前收盘价) / 前收盘价 × 100%
```

### 涨跌幅分析

#### 单日涨跌幅

| 涨跌幅 | 市场含义 |
|--------|----------|
| 涨停(+10%/+20%) | 极强买盘，或有利好消息 |
| +5%~+9% | 强势上涨 |
| +2%~+5% | 正常上涨 |
| -2%~+2% | 震荡整理 |
| -5%~-2% | 正常下跌 |
| -9%~-5% | 弱势下跌 |
| 跌停(-10%/-20%) | 极强卖盘，或有利空消息 |

#### 区间涨跌幅

- **周涨跌幅**：判断短期趋势
- **月涨跌幅**：判断中期趋势
- **年度涨跌幅**：判断长期趋势

### 涨跌幅在筛选中的应用

#### 动量策略

```
筛选条件：
- 近20日涨幅 > 10%
- 近60日涨幅 > 20%
- 成交量放大
```

寻找上升趋势中的股票。

#### 回调策略

```
筛选条件：
- 近20日跌幅 5%-15%
- 基本面良好
- 支撑位附近
```

寻找回调后的买入机会。

## 成交量

### 定义

成交量是指在一定时间内股票交易的数量，反映市场活跃程度。

### 成交量分析

#### 量价关系

| 价格 | 成交量 | 含义 |
|------|--------|------|
| 上涨 | 放量 | 健康上涨，买盘积极 |
| 上涨 | 缩量 | 上涨动力不足 |
| 下跌 | 放量 | 恐慌抛售 |
| 下跌 | 缩量 | 卖盘枯竭，可能见底 |
| 盘整 | 放量 | 方向选择中 |
| 盘整 | 缩量 | 观望情绪浓厚 |

#### 成交量筛选

在股票筛选中，成交量分为三个等级：

| 等级 | 成交额范围 | 特点 |
|------|-----------|------|
| 活跃 | >10亿元 | 流动性好，易于进出 |
| 正常 | 3-10亿元 | 流动性适中 |
| 清淡 | <3亿元 | 流动性差，交易困难 |

### 换手率

换手率是成交量与流通股本的比率：

```
换手率 = 成交量 / 流通股本 × 100%
```

| 换手率 | 市场含义 |
|--------|----------|
| <1% | 交易冷清 |
| 1-3% | 正常水平 |
| 3-7% | 相对活跃 |
| 7-10% | 高度活跃 |
| >10% | 极度活跃，需警惕 |

## 均线系统

### 移动平均线(MA)

均线是最基础的技术指标，反映一段时间内的平均成本。

#### 常用均线

| 均线 | 周期 | 用途 |
|------|------|------|
| MA5 | 5日 | 短期趋势 |
| MA10 | 10日 | 短期趋势 |
| MA20 | 20日 | 中短期趋势 |
| MA60 | 60日 | 中期趋势 |
| MA120 | 120日 | 中长期趋势（半年线） |
| MA250 | 250日 | 长期趋势（年线） |

#### 均线应用

**趋势判断**：
- 价格在均线上方：多头市场
- 价格在均线下方：空头市场
- 均线向上：上升趋势
- 均线向下：下降趋势

**金叉与死叉**：
- 金叉：短期均线上穿长期均线 → 买入信号
- 死叉：短期均线下穿长期均线 → 卖出信号

**均线多头排列**：
```
MA5 > MA10 > MA20 > MA60
→ 强势上涨趋势
```

**均线空头排列**：
```
MA5 < MA10 < MA20 < MA60
→ 弱势下跌趋势
```

## 相对强弱指标 (RSI)

### 定义

RSI（Relative Strength Index）衡量股价变动的速度和幅度，判断超买超卖状态。

### 计算公式

```
RSI = 100 - 100 / (1 + RS)
RS = 平均上涨幅度 / 平均下跌幅度
```

常用周期：RSI6、RSI12、RSI14

### RSI应用

#### 超买超卖

| RSI范围 | 状态 | 操作建议 |
|---------|------|----------|
| RSI > 80 | 超买 | 考虑卖出 |
| 70 < RSI < 80 | 强势 | 持有观察 |
| 30 < RSI < 70 | 正常 | 继续持有 |
| 20 < RSI < 30 | 弱势 | 关注机会 |
| RSI < 20 | 超卖 | 考虑买入 |

#### 背离信号

- **顶背离**：股价创新高，RSI未创新高 → 可能下跌
- **底背离**：股价创新低，RSI未创新低 → 可能上涨

## KDJ指标

### 定义

KDJ指标由K线、D线、J线组成，用于判断超买超卖和转折信号。

### 指标构成

```
RSV = (收盘价 - N日最低价) / (N日最高价 - N日最低价) × 100
K = 2/3 × 前一日K + 1/3 × RSV
D = 2/3 × 前一日D + 1/3 × K
J = 3 × K - 2 × D
```

### KDJ应用

#### 超买超卖

| 指标值 | 状态 |
|--------|------|
| K、D > 80 | 超买区 |
| K、D < 20 | 超卖区 |
| J > 100 | 极度超买 |
| J < 0 | 极度超卖 |

#### 金叉死叉

- **金叉**：K线上穿D线，在超卖区 → 买入信号
- **死叉**：K线下穿D线，在超买区 → 卖出信号

## MACD指标

### 定义

MACD（Moving Average Convergence Divergence）是最常用的趋势型指标。

### 指标构成

```
DIF = EMA12 - EMA26
DEA = EMA9 of DIF
MACD柱 = 2 × (DIF - DEA)
```

### MACD应用

#### 零轴判断

| DIF位置 | 趋势判断 |
|---------|----------|
| DIF > 0, DEA > 0 | 多头市场 |
| DIF < 0, DEA < 0 | 空头市场 |
| DIF上穿零轴 | 趋势转多 |
| DIF下穿零轴 | 趋势转空 |

#### 金叉死叉

- **金叉**：DIF上穿DEA → 买入信号
  - 零轴下方金叉：反弹信号
  - 零轴上方金叉：强势信号
  
- **死叉**：DIF下穿DEA → 卖出信号
  - 零轴上方死叉：回调信号
  - 零轴下方死叉：弱势信号

#### 背离

- **顶背离**：股价新高，MACD未新高 → 下跌预警
- **底背离**：股价新低，MACD未新低 → 上涨预警

## 布林带 (BOLL)

### 定义

布林带由中轨、上轨、下轨组成，反映价格波动的范围。

### 计算公式

```
中轨 = N日移动平均线
上轨 = 中轨 + 2 × 标准差
下轨 = 中轨 - 2 × 标准差
```

### 布林带应用

#### 波动判断

| 状态 | 含义 |
|------|------|
| 带宽收窄 | 波动减小，可能变盘 |
| 带宽扩大 | 波动增大，趋势形成 |
| 触及上轨 | 短期高点 |
| 触及下轨 | 短期低点 |

#### 操作策略

- **突破上轨**：强势，可能继续上涨
- **跌破下轨**：弱势，可能继续下跌
- **回归中轨**：正常波动范围

## 技术指标组合应用

### 趋势确认组合

```
入场信号：
✓ MA5 > MA20 （短期趋势向上）
✓ MACD金叉 （动能转强）
✓ 成交量放大 （量价配合）

出场信号：
✓ MA5 < MA20 （短期趋势转弱）
✓ MACD死叉 （动能转弱）
```

### 超跌反弹组合

```
筛选条件：
✓ RSI < 30 （超卖状态）
✓ KDJ金叉 （转折信号）
✓ 触及布林下轨 （支撑位）
✓ 成交量萎缩 （卖盘枯竭）
```

### 强势股筛选组合

```
筛选条件：
✓ 近20日涨幅 > 15%
✓ MA多头排列
✓ 成交量活跃
✓ MACD在零轴上方
```

## 技术指标局限性

### 滞后性

- 大多数技术指标基于历史数据
- 信号出现时价格已经变化
- 需要结合其他分析方法

### 钝化现象

- 强趋势中指标可能长期超买/超卖
- 不要机械地使用超买超卖信号

### 假信号

- 震荡行情中频繁出现金叉死叉
- 需要结合趋势和量能判断

## 实战建议

### 多周期验证

```
趋势判断：
- 周线级别趋势向上
- 日线级别寻找买点
- 60分钟级别精确入场
```

### 指标优先级

1. **趋势判断**：均线、MACD
2. **入场时机**：KDJ、RSI
3. **风险控制**：布林带、止损

### 风险管理

- 设置止损位
- 不要逆势操作
- 控制仓位比例
