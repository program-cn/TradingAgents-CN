# 经济周期与选股策略

## 概述

经济周期是宏观经济运行的客观规律，不同周期阶段下，各行业的表现存在显著差异。理解经济周期，顺势而为，是提升投资收益的重要方法。

## 经济周期基础

### 经济周期的四个阶段

```
        ┌─────────┐
        │ 繁荣期  │ 通胀上升 + 增长上升
        │         │
        └────┬────┘
             │
    ┌────────┴────────┐
    │                 │
┌───┴───┐         ┌───┴───┐
│复苏期 │         │滞胀期 │
│       │         │       │
│增长↑  │         │通胀↑  │
│通胀↓  │         │增长↓  │
└───┬───┘         └───┬───┘
    │                 │
    └────────┬────────┘
             │
        ┌────┴────┐
        │ 衰退期  │ 通胀下降 + 增长下降
        │         │
        └─────────┘
```

### 周期阶段特征

| 阶段 | GDP增长 | 通胀水平 | 利率趋势 | 企业盈利 | 股市表现 |
|------|---------|----------|----------|----------|----------|
| 复苏期 | 加速上升 | 维持低位 | 开始上升 | 快速恢复 | 震荡上行 |
| 繁荣期 | 高位运行 | 加速上升 | 持续上升 | 保持高位 | 波动加大 |
| 滞胀期 | 增速放缓 | 高位运行 | 维持高位 | 边际下滑 | 风险增加 |
| 衰退期 | 明显下滑 | 开始回落 | 开始下降 | 明显下滑 | 持续下跌 |

## 通胀与通缩分析

### 通胀的定义与类型

**定义**：一般物价水平持续上涨的现象

| 通胀类型 | 成因 | 特征 |
|----------|------|------|
| 需求拉动型 | 总需求超过总供给 | 经济过热，消费旺盛 |
| 成本推动型 | 生产成本上升 | 工资、原材料价格上涨 |
| 货币型 | 货币供应过量 | 流动性泛滥 |
| 输入型 | 进口商品价格上涨 | 汇率贬值、大宗商品涨价 |

### 通缩的定义与影响

**定义**：一般物价水平持续下降的现象

**通缩的影响**：

```
通缩传导链条：
物价下降 → 消费延迟 → 需求萎缩 → 
企业降价 → 利润下降 → 投资减少 → 
就业下降 → 收入减少 → 消费进一步萎缩
```

### 通胀与通缩对行业的影响

#### 通胀环境下受益行业

| 行业 | 受益逻辑 | 投资策略 |
|------|----------|----------|
| **资源类** | 产品价格上涨，盈利提升 | 强烈推荐 |
| **银行** | 名利差扩大，资产升值 | 推荐 |
| **地产** | 资产升值，抗通胀属性 | 关注政策 |
| **消费品** | 涨价能力，品牌溢价 | 龙头优先 |
| **农业** | 农产品价格上涨 | 关注天气 |

**通胀期选股要点**：
```
✓ 选择定价能力强的企业
✓ 关注成本转嫁能力
✓ 资源类、消费类优先
✗ 避免高负债企业
```

#### 通胀环境下受损行业

| 行业 | 受损逻辑 | 投资策略 |
|------|----------|----------|
| **公用事业** | 价格管制，成本上升 | 谨慎 |
| **高负债企业** | 实际债务加重 | 回避 |
| **消费降级品** | 需求弹性大 | 谨慎 |
| **出口企业** | 汇率压力 | 关注汇率 |

#### 通缩环境下受益行业

| 行业 | 受益逻辑 | 投资策略 |
|------|----------|----------|
| **高现金流企业** | 现金实际价值上升 | 推荐 |
| **低负债企业** | 债务实际负担不变 | 推荐 |
| **必需消费品** | 需求刚性，销量稳定 | 防御配置 |
| **公用事业** | 现金流稳定 | 防御配置 |

#### 通缩环境下受损行业

| 行业 | 受损逻辑 | 投资策略 |
|------|----------|----------|
| **重资产企业** | 资产贬值 | 回避 |
| **高库存企业** | 存货跌价 | 回避 |
| **高负债企业** | 债务实际负担加重 | 谨慎 |
| **周期股** | 需求萎缩 | 回避 |

### 不同通胀水平的行业配置

| 通胀水平 | CPI区间 | 配置重点 | 回避行业 |
|----------|---------|----------|----------|
| 通缩 | CPI < 0 | 现金、债券、防御股 | 周期股、地产 |
| 低通胀 | 0-2% | 成长股、科技股 | 无明显回避 |
| 温和通胀 | 2-4% | 消费股、银行、资源 | 公用事业 |
| 高通胀 | 4-6% | 资源股、抗通胀资产 | 高负债企业 |
| 恶性通胀 | >6% | 实物资产、黄金 | 大多数股票 |

## 四周期选股策略

### 复苏期选股策略

**经济特征**：
- GDP增速触底回升
- 通胀维持低位
- 政策开始宽松
- 企业盈利改善

**最佳配置**：

| 优先级 | 行业 | 逻辑 |
|--------|------|------|
| ⭐⭐⭐⭐⭐ | 金融（券商、银行） | 流动性宽松，交易活跃 |
| ⭐⭐⭐⭐⭐ | 地产 | 政策宽松，利率下降 |
| ⭐⭐⭐⭐ | 可选消费 | 收入预期改善 |
| ⭐⭐⭐⭐ | 工业制造 | 需求回升 |
| ⭐⭐⭐ | 周期品 | 价格触底反弹 |

**复苏期投资组合示例**：
```
核心仓位（50%）：
- 券商龙头：20%
- 银行龙头：15%
- 地产龙头：15%

成长仓位（30%）：
- 科技成长：15%
- 消费成长：15%

机动仓位（20%）：
- 周期股：10%
- 现金：10%
```

### 繁荣期选股策略

**经济特征**：
- GDP增速较高
- 通胀开始上升
- 利率持续上行
- 企业盈利高位

**最佳配置**：

| 优先级 | 行业 | 逻辑 |
|--------|------|------|
| ⭐⭐⭐⭐⭐ | 周期股（有色、煤炭） | 商品价格上涨 |
| ⭐⭐⭐⭐⭐ | 能源 | 油价上涨 |
| ⭐⭐⭐⭐ | 银行 | 利率上行，利差扩大 |
| ⭐⭐⭐⭐ | 基础材料 | 价格上涨 |
| ⭐⭐⭐ | 工业品 | 需求旺盛 |

**繁荣期投资组合示例**：
```
核心仓位（50%）：
- 有色金属：20%
- 煤炭石油：15%
- 化工龙头：15%

配置仓位（30%）：
- 银行保险：15%
- 工业制造：15%

防御仓位（20%）：
- 消费龙头：10%
- 现金：10%
```

### 滞胀期选股策略

**经济特征**：
- GDP增速放缓
- 通胀高位运行
- 利率维持高位
- 企业盈利下滑

**最佳配置**：

| 优先级 | 行业 | 逻辑 |
|--------|------|------|
| ⭐⭐⭐⭐⭐ | 能源 | 油价维持高位 |
| ⭐⭐⭐⭐⭐ | 必需消费 | 需求刚性 |
| ⭐⭐⭐⭐ | 公用事业 | 现金流稳定 |
| ⭐⭐⭐⭐ | 医药 | 防御属性 |
| ⭐⭐⭐ | 黄金 | 抗通胀保值 |

**滞胀期投资组合示例**：
```
防御仓位（60%）：
- 必需消费：20%
- 公用事业：20%
- 医药龙头：20%

通胀对冲（30%）：
- 能源股：15%
- 黄金/资源：15%

现金仓位（10%）：
- 现金：10%
```

### 衰退期选股策略

**经济特征**：
- GDP负增长或低增长
- 通胀开始回落
- 利率持续下降
- 企业盈利恶化

**最佳配置**：

| 优先级 | 行业 | 逻辑 |
|--------|------|------|
| ⭐⭐⭐⭐⭐ | 公用事业 | 防御性最强 |
| ⭐⭐⭐⭐⭐ | 必需消费 | 需求稳定 |
| ⭐⭐⭐⭐ | 医药 | 刚需属性 |
| ⭐⭐⭐⭐ | 高股息股 | 收益确定性 |
| ⭐⭐⭐ | 债券替代 | 利率下降受益 |

**衰退期投资组合示例**：
```
防御仓位（70%）：
- 公用事业：25%
- 必需消费：25%
- 医药龙头：20%

高股息（20%）：
- 银行高股息：10%
- 高速公路：10%

现金仓位（10%）：
- 现金：10%
```

## 经济周期判断方法

### 宏观指标监测

| 指标类别 | 关键指标 | 判断标准 |
|----------|----------|----------|
| **增长指标** | GDP、工业增加值 | 同比趋势判断 |
| **通胀指标** | CPI、PPI | 水平与趋势 |
| **货币指标** | M2、社融 | 增速变化 |
| **利率指标** | 10年期国债 | 水平与趋势 |
| **景气指标** | PMI | 荣枯线以上/以下 |

### 周期拐点识别

```
复苏信号：
✓ PMI触底回升
✓ 社融增速企稳
✓ 企业盈利改善
✓ 政策边际宽松

见顶信号：
✓ PMI高位回落
✓ 通胀加速上升
✓ 利率持续上行
✓ 政策开始收紧

衰退信号：
✓ GDP增速下滑
✓ 通胀开始回落
✓ 企业盈利恶化
✓ 失业率上升
```

### 领先指标应用

| 指标 | 领先期 | 应用方法 |
|------|--------|----------|
| 社融增速 | 3-6个月 | 预测经济拐点 |
| PMI | 1-3个月 | 判断短期方向 |
| 利率 | 3-6个月 | 预测政策变化 |
| 房地产销售 | 3-6个月 | 预测经济走势 |

## 特殊周期分析

### 库存周期

```
库存周期四阶段：
1. 主动补库存：需求旺盛，企业主动增加库存
2. 被动补库存：需求下滑，库存被动增加
3. 主动去库存：需求疲软，企业主动减少库存
4. 被动去库存：需求回升，库存被动下降

周期长度：3-4年
```

**库存周期与行业配置**：

| 阶段 | 特征 | 配置行业 |
|------|------|----------|
| 主动补库存 | 需求强，库存增 | 周期股、制造业 |
| 被动补库存 | 需求弱，库存增 | 谨慎，降低仓位 |
| 主动去库存 | 需求弱，库存减 | 防御股、现金 |
| 被动去库存 | 需求强，库存减 | 布局周期股 |

### 信用周期

```
信用周期：
- 宽信用：信贷扩张，经济上行
- 紧信用：信贷收缩，经济下行

信用周期与股市：
- 宽信用初期：股市见底
- 宽信用后期：股市见顶
- 紧信用期：股市下跌
```

## 实战案例分析

### 案例1：2020年疫情周期

```
阶段划分：
2020Q1：衰退期（疫情冲击）
2020Q2-2020Q4：复苏期（政策刺激）
2021Q1-Q2：繁荣期（经济反弹）
2021Q3-至今：滞胀预期

投资策略：
Q1：防御为主，配置医药、必需消费
Q2-Q4：转向进攻，配置新能源、科技
2021：逐步转向防御，配置资源、消费
```

### 案例2：2016-2018年周期

```
阶段划分：
2016年：复苏期（供给侧改革）
2017年：繁荣期（经济高位）
2018年：衰退期（去杠杆）

行业表现：
2016年：周期股表现优异
2017年：消费股、银行上涨
2018年：全市场下跌，防御股抗跌
```

## 周期投资的风险与应对

### 主要风险

1. **周期判断错误**：误判周期阶段
2. **政策干扰**：政策提前或滞后
3. **外部冲击**：黑天鹅事件
4. **结构性变化**：周期规律失效

### 应对策略

```
风险管理：
1. 分散配置，不押注单一阶段
2. 动态调整，及时纠错
3. 关注领先指标，提前布局
4. 保持一定现金仓位
5. 设置止损，控制回撤
```

## 总结

经济周期投资的核心要点：

1. **识别周期**：通过宏观指标判断当前阶段
2. **顺势而为**：根据周期配置相应行业
3. **动态调整**：持续跟踪，及时调整
4. **风险控制**：分散配置，控制仓位
